OUR MONTHSARY GIFT — QUICK START

1. Extract this ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser. Recommended: install Live Server in VS Code, right-click index.html, then select Open with Live Server.

PERSONALIZE IT
Open index.html and find the CONFIG object near the bottom of the file. Change girlfriendName, yourName, monthsary, songTitle, songArtist, youtubeUrl, and letter. Save and refresh your browser.

PHOTOS
On the Letter page, choose a photo file inside each of the three Polaroid frames. These selections are local to your current browser session. For photos to appear for everyone after publishing, add image files to the project and set the img src paths in index.html.

PUBLISH FREE WITH GITHUB PAGES
1. Create a GitHub account and a new repository.
2. Upload index.html and README.txt.
3. Open repository Settings > Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub Pages to provide your public website link.

No database, login, or AI credits are needed. Internet is required for Google Fonts and YouTube embeds.
